Cloud projects

Posted On : 12/09/2026
Designed and implemented an end-to-end real-time data analytics pipeline on Google Cloud Platform (GCP) to process and analyze streaming event data. The architecture leveraged Google Cloud Pub/Sub for high-throughput ingestion, which was seamlessly processed and transformed using Cloud Dataflow (via Apache Beam). The cleaned data was continuously streamed into Google BigQuery to serve as a centralized data warehouse. Finally, I built interactive dashboards in Looker Studio to expose key metrics and business trends, reducing time-to-insight for operational stakeholders from hours to near real-time.

Jog falls

Posted On : 10/07/2026
